# 租屋

自從疫情結束後，幾經周遊如今又到醫院工作

不過啊，醫院這個龐大的生態系，要融洽合作相處可真不容易呀

走完入職程序後，馬上開診，熟悉系統操作，同時迅速熟悉門診、開刀房、病房的工作習慣，每家醫院大不相同，除了過去學會的臨床知識外，一切都要重新學習適應

新的工作夥伴、不同的職場規則、嶄新的願景...一切都與往常不一樣

唯一不變的是，自己仍希望能在變化莫測的未來中持續成長

---

我不希望每日通車時間佔用太多的時間、油錢，並且為了能夠立即處理急診，入職不久就馬上在醫院附近找租屋搬家

打開591，從金額小到大逐一看起，小於1萬5的租屋大多都是透天改建的隔間套房，總面積不超過10坪居多

（面積大於10坪的，要小心其他扣分條件，頂加、無窗採光...）

第一間是套房公寓，專門出租用，每一間約8坪的小套房，配件齊全、水電隨帳單繳費

只不過一走進去房間就聞到不一樣的味道，看看角落放著檸檬味的去味大師...

誒 怎麼這麼違和

檸檬為趣味大師不是這個味道的說...

哦... 前房客留下的菸房


第二間則是房東自經營管理的多房隔間頭天

房東將連棟的老透天整建、打掉每一層樓棟間的牆壁，再輕裝潢隔間出多個獨立套房

（是『輕裝潢』）

陽台外推放加高的廁所浴室，剩下的則留作洗衣陽台

統一的系統櫃傢俱床櫃

看似完美的外表下 一進屋問題就現形了

整棟連棟透天套房，水泥牆都敲的一乾二淨

除了木作輕隔間外，幾乎沒有聲音隔絕的效果

而且天花板先統一矽酸蓋板封頂，再做輕隔間牆

上方空間完全沒有聲音阻隔 隔壁房間說話洗澡上廁所的聲音都聽得一清二楚

尤其是方正的廁所回音更大

整棟樓層裡外都是不同房間的回音

另外 起碼浴室鋪個磁磚吧

只有輕隔間 就算有開窗通風

總有一天還是會發霉的


第三間 巷內國宅新村老屋紅磚房 只有二層樓

巷子窄的現代車進來都有困難 所以是只有機車會通過的靜巷

頂加層 鐵皮牆內用輕隔間與輕鋼架天花板隔出前後2房

沒有磚牆包覆 嚴格上算屋外

螞蟻、昆蟲會沿著輕鋼架天花板爬進房間

隔音也最差
